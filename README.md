# Proyecto GraphHopper Routes

Este proyecto permite obtener rutas utilizando la API de GraphHopper y traducir resultados con Google Translate.

## Requisitos

- Python 3
- Librería `googletrans` versión `4.0.0-rc1`

Instalación de la librería:

```bash
pip3 install googletrans==4.0.0-rc1
```
## Uso del script:

```bash
python3 graphhoper_routes_dicc.py
```
